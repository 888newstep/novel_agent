# Code of Conduct

We want this repository to be welcoming, respectful, and useful for everyone.

## Our Standards

Examples of behavior that help create a positive environment:

- being respectful in reviews and discussions
- giving constructive and actionable feedback
- assuming good intent while discussing tradeoffs
- focusing criticism on ideas, code, and decisions, not people

Examples of unacceptable behavior:

- harassment, insults, or personal attacks
- discriminatory or hateful language
- publishing private information without permission
- repeated disruptive behavior in issues, pull requests, or discussions

## Enforcement

Project maintainers may edit, remove, or reject contributions and discussions that violate this code of conduct.

## Reporting

If you experience or witness unacceptable behavior, open a private security/advisory report when available, or contact the maintainer through GitHub with enough context for investigation.
